# Kaiju Archives

**Kaiju Archives** es un proyecto escolar desarrollado por *Gabriel García* como una introducción al desarrollo web con **HTML**, **CSS** y **JavaScript**.

El objetivo del sitio es presentar una galería interactiva dedicada al universo de los **kaijus** (monstruos gigantes) del **MonsterVerse** y **Toho Studios**, 
permitiendo explorar información básica y detallada sobre cada criatura.
